# Проверка блокировок счёта через сервис ФНС «Банкинформ»

## Когда использовать
- Проверка, действует ли блокировка расчётного счёта (ст. 76 НК)
- Контроль снятия блокировки после приёма отчётности (п. 3.1 ст. 76 НК — автоматически, не позднее следующего рабочего дня)
- Диагностика причины блокировки по коду основания

## Как проверять (браузер)

1. Открыть https://service.nalog.ru/bi.do
2. Тип запроса: «Запрос о действующих приостановлениях операций по счетам» (radio `requestType_FINDPRS`)
3. Заполнить: ИНН (`innPRS`) + БИК банка счёта (`bikPRS`)
4. Кнопка «Отправить запрос» (`btnSearch`)
5. Результат — строка «Действующие приостановления операций по счетам по указанному налогоплательщику ИМЕЮТСЯ / НЕТ» + таблица (номер, даты, код основания, код налогового органа, БИК, дата размещения информации)

## Капча — критично (проверено 13.10.2026)
- При БЫСТРЫХ повторных запросах сервис показывает капчу: «Вы превысили лимит запросов, направляемых в единицу времени» — модалка с 5 цифрами (iframe `captcha-dialog.html`, input `#captcha`, кнопка `#btnOk`)
- Порядок решения: извлечь `src` картинки из iframe → прочитать через vision_analyze → ввести цифры в `#captcha` → клик `#btnOk`
- После паузы повторный запрос проходит БЕЗ капчи — не делай серии запросов подряд
- Если submit не срабатывает: убедись, что радио выбрано, а поля заполнены через `dispatchEvent(new Event('input'/'change'))` — иначе значения не регистрируются формой

## Коды основания приостановления
| Код | Значение |
|---|---|
| 01 | Принятие решения о взыскании задолженности |
| 02 | Непредставление декларации/расчёта в течение 20 дней после срока |
| 03 | Обеспечение исполнения решения о привлечении к ответственности |
| 04 | Не передана квитанция о приёме требования о представлении пояснений (в течение 10 дней после истечения срока квитанции) |

## Что делать по результату
- «ИМЕЮТСЯ» + основание устранено (отчёт принят, требование закрыто): снятие автоматическое, не позднее следующего рабочего дня после приёма отчёта (п. 3.1 ст. 76 НК). Сервис обновляется с лагом — смотри «дату и время размещения информации»: старая дата = отмена ещё не ушла в банк
- Не снята в срок: обращение в ИФНС (или через ЛК) с квитанцией о приёме отчёта — приложить PDF квитанции, зафиксировать дату приёма
- Несколько строк = несколько блокировок — закрывать по очереди
- «НЕТ»: блокировок нет — расходные операции должны работать

## Данные ООО «РАМЕВА»
- ИНН [INN], ИФНС 4800 (УФНС по Липецкой области)
- БИК счёта на 13.10.2026: [BIK] (уточнять у директора при смене банка)
- История: блокировка № 105718359 от 07.10.2026, основание 02 (непредставление РСВ за II квартал). Первичный РСВ принят 13.10.2026 в 03:55 — основание устранено
